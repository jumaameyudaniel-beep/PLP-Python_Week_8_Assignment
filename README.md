# My Python Toolkit – PLP Week 8 Final Project# My Python Toolkit – PLP Week 8 Final Project

## Project Description

My Python Toolkit is a menu-driven program that brings together different Python programming concepts. It provides four useful tools: a simple calculator, a to-do list, a number checker, and a countdown.

## Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List:** Allows users to add, view, and remove tasks.
3. **Number Checker:** Identifies whether a number is positive, negative, or zero.
4. **Countdown:** Counts backwards from a number entered by the user.

## Python Concepts Used

- Variables
- User input and output
- If, elif, and else statements
- While and for loops
- Lists
- Functions
- F-strings
- Error handling using try and except

## Project Files

- `toolkit_plan.txt` – Contains the project plan and menu design.
- `toolkit.py` – Contains the complete Python toolkit program.
- `README.md` – Explains the project and how to run it.
- `screenshots/` – Contains screenshots showing the program and its tools.

## How to Run the Program

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python toolkit.py
```

5. Select a tool from the menu and follow the instructions.

## Project Reflection

The hardest part of this project was creating the menu loop and making sure it returned after each tool finished. The bug that took the longest to fix was handling invalid user input without allowing the program to crash. I used conditionals to control the menu and try-except statements to handle incorrect number entries. I also learned how lists can store information that changes while a program is running. Writing separate functions made the program easier to understand and maintain. I am proud that the toolkit combines several Python concepts in one program. If I had one more week, I would add a tool that saves the to-do list to a file so tasks remain available after the program closes.
